# Lumina screenshots

## Current status
The repository banner at `docs/assets/lumina-banner.svg` is decorative project artwork, **not an in-app screenshot**. No actual device/emulator screenshots were available during this README refresh, so none are presented as genuine app captures.

## Recommended screenshots to add
Capture the current app on an emulator or device, then save the unaltered captures here:

1. `docs/screenshots/home.png` — start screen / wallpaper.
2. `docs/screenshots/browser.png` — web page and browser controls.
3. `docs/screenshots/tabs.png` — tab switcher.
4. `docs/screenshots/ai-chat.png` — Gemini chat (remove private page content and personal data).
5. `docs/screenshots/settings.png` — theme and personalization settings.

Use the Android emulator screenshot control or the device's screenshot feature. Avoid including API keys, passwords, private browsing history, personal notifications, or account details.

## Add captures to the README
Once real captures exist, use Markdown image links, for example:

```md
![Lumina start screen](screenshots/home.png)
```

Keep images optimized and ensure each screenshot matches the current code.
