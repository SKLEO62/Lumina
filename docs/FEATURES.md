# Lumina Browser — feature overview

This page summarizes capabilities documented in the repository README. It is not an independent test report; use the app itself and its current source to verify behavior in a specific build.

## Lumina Intellect — Gemini AI
- Full-screen AI chat.
- Page summaries and key-fact extraction.
- Simplified explanations and custom questions about page content.
- Page comparisons, fact-checking, and translation.
- Smart task extraction from web pages, recipes, and documentation into an interactive checklist.

## Start screen and personalization
- Translucent start screen.
- Adjustable wallpaper blur and dimming.
- Bundled cosmic and abstract wallpapers, plus custom photo backgrounds.
- Five Material 3 palettes: Obsidian, Neon, Deep Space, Emerald, and Light.

## Privacy and browsing
- Built-in ad and tracker blocking.
- Incognito browsing.
- Secure vault described for passwords, history, and downloads.
- One-tap browsing-data cleanup.

## Navigation and reading
- Regular and incognito tabs.
- Grouped spaces and pinned tabs.
- Custom vector icons for GitHub, Wikipedia, Telegram, Reddit, Habr, Yandex, X/Twitter, and DuckDuckGo.
- Reader mode and text-to-speech.
- QR code generator/scanner.
- Sticky web notes associated with specific domains.

## Technology noted by the project
- Kotlin
- Jetpack Compose and Material Design 3
- Firebase AI Logic / Gemini API
- SharedPreferences and StateFlow
- MVVM / Clean Architecture

Feature list reflects project documentation and should not be read as a guarantee that every feature has passed QA on every device.
