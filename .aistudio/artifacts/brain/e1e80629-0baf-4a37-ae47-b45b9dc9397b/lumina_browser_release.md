# ✦ Lumina Browser — Обновление: Пользовательские обои из галереи

В браузер **Lumina** добавлена возможность установки собственных картинок и фотографий на фон домашней страницы напрямую из галереи смартфона.

---

## 📸 Новые возможности в этом обновлении

### 1. Выбор любого фото из галереи (Android Photo Picker)
- Поддержка форматов **JPEG, PNG, WebP**.
- **0 разрешений (Zero-Permission):** используется современный Android Photo Picker (`ActivityResultContracts.PickVisualMedia`). Приложению не требуется доступ ко всем файлам устройства.
- Выбранное изображение безопасно кэшируется во внутреннем каталоге приложения, благодаря чему фон не сбрасывается при перезагрузке или очистке кэша галереи.

### 2. Размытие фона (Frosted Glass Effect)
- Новый ползунок регулировки эффекта размытия **от 0 до 25 dp** с интерактивным предпросмотром.
- Позволяет превратить любую пеструю фотографию в стильную подложку в духе стекла (Glassmorphism), сохраняя идеальный контраст текста и закладок.

### 3. Затемнение фона (Dimming Scrim)
- Настройка затемнения фона **от 15% до 85%**.
- Обеспечивает комфортную читаемость омнибокса, виджетов и карточек сайтов на ярких снимках.

### 4. Управление обоями
- В нижней шторке «Фон браузера» отображается миниатюра вашего текущего фото с галочкой активности.
- Кнопки **«Сменить»** для быстрого выбора другого снимка и **«Удалить»** (корзина) для возврата к встроенным космическим/неоновым темам.
